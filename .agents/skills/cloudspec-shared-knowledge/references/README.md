## CloudSpec IDL AI 文档语料和 Prompt 仓库

## 项目简介

本仓库用于存储 CloudSpec IDL 相关的 AI 文档语料和 Prompt，为 AI 模型训练和推理提供标准化的输入输出规范。

## 目录结构

```
.
├── README.md
├── .gitignore
└── docs/
    ├── prompts/
    └── corpora/
```

## 使用说明

### 文档语料 (Corpora)

位于 `docs/corpora/` 目录下，包含用于训练和评估 AI 模型的各种文档语料。

### Prompt 模板

位于 `docs/prompts/` 目录下，包含各种标准化的 Prompt 模板，用于指导 AI 模型生成符合 CloudSpec IDL 规范的内容。

## 贡献指南

1. 所有新增的语料和 Prompt 需要遵循统一的格式规范
2. 提交前请确保内容的准确性和完整性
3. 遵循 Git 提交规范，提供清晰的提交信息

## 解决方案汇总

### 通用解决步骤
1. **查看详细日志**: 检查 `/logs/test-run-detail.log`
2. **检查FAQ目录**: 查看 `docs/faq` 目录是否有类似问题
3. **验证参数**: 对照API文档验证参数
4. **检查依赖**: 确认前置依赖资源是否创建成功

### 常用技巧
1. **使用动态参数**: 避免硬编码，使用 `{{$.resource.field}}` 引用
2. **简化测试用例**: 只保留必需参数，去除可选参数
3. **正确的namespace**: 确保import语句的namespace格式正确
4. **合理的超时设置**: 某些资源创建时间较长，需要调整超时
5. **重试机制**: 网络问题可以通过重试解决

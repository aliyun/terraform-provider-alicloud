# alicloud_apig_gateway_security_group_rule

Provides an API Gateway (ApiG) gateway security group rule resource.

For information about ApiG and how to use it, see [What is API Gateway](https://www.alibabacloud.com/help/en/api-gateway/).

-> **NOTE:** Available since v1.214.0.

## Example Usage

Basic Usage

```terraform
variable "name" {
  default = "tf-example"
}

data "alicloud_vpcs" "default" {
  name_regex = "^default-NODELETING$"
}
data "alicloud_vswitches" "default" {
  vpc_id = data.alicloud_vpcs.default.ids.0
}

resource "alicloud_security_group" "default" {
  vpc_id = data.alicloud_vpcs.default.ids.0
  name   = "${var.name}-sg"
}

resource "alicloud_apig_gateway" "default" {
  network_access_config {
    type = "Intranet"
  }
  vswitch {
    vswitch_id = data.alicloud_vswitches.default.ids.0
  }
  zone_config {
    select_option = "Auto"
  }
  vpc {
    vpc_id = data.alicloud_vpcs.default.ids.0
  }
  payment_type = "PayAsYouGo"
  gateway_name = "${var.name}-gw"
  spec         = "apigw.small.x1"
  log_config {
    sls {
    }
  }
}

resource "alicloud_apig_gateway_security_group_rule" "default" {
  gateway_id        = alicloud_apig_gateway.default.id
  security_group_id = alicloud_security_group.default.id
  port_range        = "8080/8080"
  description       = "tf-example-security-group-rule"
}
```

## Argument Reference

The following arguments are supported:

* `gateway_id` - (Required, ForceNew) The ID of the API Gateway to which the security group rule belongs.
* `security_group_id` - (Required, ForceNew) The ID of the security group that is authorized to access the gateway.
* `port_range` - (Required, ForceNew) The port range of the security group rule. The value is in the format of `startPort/endPort`, for example `8080/8080`.
* `description` - (Optional, ForceNew) The description of the security group rule.

## Attributes Reference

The following attributes are exported:

* `id` - The resource ID in format `gatewayId:securityGroupRuleId`.
* `security_group_rule_id` - The ID of the security group rule generated by the system.
* `source_security_group_id` - The ID of the source security group.
* `ip_protocol` - The IP protocol of the security group rule.

## Import

API Gateway security group rule can be imported using the id, e.g.

```shell
$ terraform import alicloud_apig_gateway_security_group_rule.example <gateway_id>:<security_group_rule_id>
```

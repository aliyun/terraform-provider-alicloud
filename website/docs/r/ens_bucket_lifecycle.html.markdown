For information about ENS Bucket Lifecycle and how to use it, see [What is BucketLifecycle](https://www.alibabacloud.com/help/en/ens/developer-reference/).

## Argument Reference

The following arguments are supported:

* `allow_same_action_overlap` - (Optional, ForceNew) Whether prefix overlap is allowed. Valid values: `true`, `false`. Default to `false`.
* `bucket_name` - (Required, ForceNew) The name of the ENS bucket to which the lifecycle rule applies.
* `expiration_days` - (Optional) The number of days after the last update of the object before the lifecycle rule takes effect. The value must be greater than 0 and is a positive integer.
* `prefix` - (Optional) The prefix that the rule applies to. The same prefix cannot be set for multiple rules. If prefix is empty, the rule applies to all objects in the bucket.
* `rule_id` - (Computed) The unique ID of the rule, automatically generated by the system when a new rule is created. It cannot be specified by the user.
* `status` - (Optional) The rule status. Valid values: `Enabled`, `Disabled`. `Enabled` means the rule is executed periodically; `Disabled` means the rule is ignored.

## Attributes Reference

The following attributes are exported:

* `id` - The ID of the resource. It is formatted as `<bucket_name>:<rule_id>`.

## Timeouts

The `timeouts` block allows you to specify [timeouts](https://developer.hashicorp.com/terraform/language/resources/syntax#operation-timeouts) for certain actions:

* `create` - (Defaults to 5 mins) Used when create the Bucket Lifecycle.
* `update` - (Defaults to 5 mins) Used when update the Bucket Lifecycle.
* `delete` - (Defaults to 5 mins) Used when delete the Bucket Lifecycle.

## Import

ENS Bucket Lifecycle can be imported using the id, e.g.

```shell
$ terraform import alicloud_ens_bucket_lifecycle.example <bucket_name>:<rule_id>
```

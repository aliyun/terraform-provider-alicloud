# alicloud_api_gateway_app_key

Provides an API Gateway App Key resource. An App Key (together with its AppSecret and AppCode) is the credential an App uses to call a published API. Each App can hold multiple App Keys; this resource manages one App Key under a given App.

For information about API Gateway App Key and how to use it, see [CreateAppKey](https://www.alibabacloud.com/help/en/api-gateway/latest/api-cloudapi-2016-07-14-createappkey).

-> **NOTE:** Available since v2.2.0.

-> **NOTE:** `app_key`, `app_secret` and `app_code` are generated by the server when the App Key is created and are read back through `DescribeAppSecurities`. They are sensitive and read-only. To rotate the `app_secret` in place, change the value of `secret_reset_token`; the provider calls `ResetAppSecret` and reads the new `app_secret` back. Changing the `app_key` identity itself would change the resource's primary id (`<app_id>:<app_key>`) and is therefore a ForceNew (triggered by changing `app_id`).

-> **NOTE:** `CreateAppKey` only returns a `RequestId`, so the provider reads the newly created App Key back from `DescribeAppSecurities` by diffing the App's App Keys before and after creation. Avoid creating App Keys for the same App concurrently from multiple writers.

## Example Usage

Basic Usage

```terraform
terraform {
  required_providers {
    alicloud = {
      source = "aliyun/alicloud"
    }
  }
}

variable "name" {
  default = "terraform-example"
}

resource "alicloud_api_gateway_group" "default" {
  name        = var.name
  description = "tf_example"
}

resource "alicloud_api_gateway_app" "default" {
  name        = var.name
  description = "tf_example"
}

resource "alicloud_api_gateway_app_key" "default" {
  app_id = alicloud_api_gateway_app.default.id
}
```

### Rotate the AppSecret

To rotate the `app_secret` without recreating the resource, change `secret_reset_token` to any new value. The token itself is not sent to the server; only the change between configurations triggers a rotation.

```terraform
resource "alicloud_api_gateway_app_key" "default" {
  app_id            = alicloud_api_gateway_app.default.id
  secret_reset_token = "v2"
}
```

## Argument Reference

The following arguments are supported:

* `app_id` - (Required, ForceNew) The ID of the App to which the App Key belongs.
* `secret_reset_token` - (Optional) An arbitrary value that, when changed, rotates the `app_secret` by calling `ResetAppSecret`. The value itself is not sent to the server; only a change between configurations triggers rotation.

## Attributes Reference

The following attributes are exported:

* `id` - The ID of the App Key, formatted as `<app_id>:<app_key>`.
* `app_key` - (Sensitive) The AppKey generated for the App.
* `app_secret` - (Sensitive) The AppSecret generated for the App. Rotate it by changing `secret_reset_token`.
* `app_code` - (Sensitive) The AppCode generated for the App.
* `created_time` - The time when the App Key was created.
* `modified_time` - The time when the App Key was last modified.

## Import

Api gateway app key can be imported using the id, e.g. `<app_id>:<app_key>`

```shell
$ terraform import alicloud_api_gateway_app_key.example "110862931:34379343"
```

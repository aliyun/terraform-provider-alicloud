# alicloud_pai_virtual_resource

Provides a PAI EAS Virtual Resource resource.

A virtual resource groups one or more physical resource pools (public resource groups, dedicated resource groups, or Lingjun quota) that an EAS service can run on.

For information about PAI EAS Virtual Resource and how to use it, see [CreateVirtualResource](https://www.alibabacloud.com/help/en/pai/developer-reference/api-eas-2021-07-01-createvirtualresource).

-> **NOTE:** Available since v1.295.0.

## Example Usage

Basic Usage

```terraform
resource "alicloud_pai_virtual_resource" "example" {
  virtual_resource_name          = "tf-example"
  disable_spot_protection_period = false

  resources {
    instance_type    = "ecs.s6-c1m2.xlarge"
    region           = "cn-hangzhou"
    priority         = 6
    spot_price_limit = 10.05
  }
}
```

## Argument Reference

The following arguments are supported:

* `virtual_resource_name` - (Optional) The name of the virtual resource. It defaults to the virtual resource ID when left unset.
* `cluster_id` - (Optional) The ID of the cluster. It defaults to the current region.
* `disable_spot_protection_period` - (Optional) Whether to disable the retention period of preemptible instances.
* `resources` - (Optional) The resource pools backing the virtual resource. Each entry must specify exactly one of `instance_type`, `resource_id` and `quota_id`. See [`resources`](#resources) below.

### `resources`

`resources` supports the following:

* `instance_type` - (Optional) The instance type of the public resource group, such as `ecs.s6-c1m2.xlarge`. One of `instance_type`, `resource_id`, `quota_id` must be set.
* `resource_id` - (Optional) The ID of the dedicated resource group, such as `eas-r-g55ieatgg3buxxxxxx`. One of `instance_type`, `resource_id`, `quota_id` must be set.
* `quota_id` - (Optional) The quota ID of the Lingjun resource group, such as `quota185lqxxxxxx`. One of `instance_type`, `resource_id`, `quota_id` must be set.
* `region` - (Optional) The region of the resource.
* `priority` - (Optional) The scheduling priority of the resource. A larger number means a higher priority.
* `spot_price_limit` - (Optional) The maximum price of a preemptible instance of the public resource group. Unset means no preemptible instance is used.

## Attributes Reference

The following attributes are exported:

* `id` - The ID of the resource, in the format `<cluster_id>:<virtual_resource_id>`.
* `virtual_resource_id` - The ID of the virtual resource, generated by the server on creation.
* `create_time` - The time when the virtual resource was created.
* `update_time` - The time when the virtual resource was last updated.
* `service_count` - The number of services running on the virtual resource.
* `features` - The features enabled on the virtual resource.

## Import

PAI EAS Virtual Resource can be imported using the id, e.g.

```shell
$ terraform import alicloud_pai_virtual_resource.example <cluster_id>:<virtual_resource_id>
```

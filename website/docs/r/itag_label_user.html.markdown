# alicloud_itag_label_user

Provides a iTAG Label User resource.

For information about iTAG Label User and how to use it, see [iTAG LabelUser](https://www.alibabacloud.com/help/en/itag/developer-reference/api-openitag-2022-06-16-createuser).

-> **NOTE:** Available since v1.295.0.

## Example Usage

Basic Usage

```terraform
data "alicloud_ram_users" "example" {
  ids = ["166***980757310"]
}

resource "alicloud_itag_label_user" "example" {
  tenant_id    = "GAR***W134"
  account_no   = data.alicloud_ram_users.example.users.0.unique_id
  account_type = "ALIYUN"
  role         = "OPERATOR"
  user_name    = "tf-example"
}
```

## Argument Reference

The following arguments are supported:

* `tenant_id` - (Required, ForceNew) The tenant ID of the iTAG service. It can be obtained via the ListTenants API.
* `account_no` - (Required, ForceNew) The UID of the RAM user (sub-account) under the current Alibaba Cloud account (primary account).
* `account_type` - (Required, ForceNew) The account type. Currently, only `ALIYUN` is supported.
* `role` - (Required) The role of the user. Valid values: `OPERATOR`, `ADMIN`, `LEADER`.
* `user_name` - (Optional) The user name. If omitted, the service derives one from the bound RAM user.

## Attributes Reference

The following attributes are exported:

* `id` - The ID of the resource, in the format `<tenant_id>:<user_id>`.
* `user_id` - The ID of the label user, generated by the service.

## Import

iTAG Label User can be imported using the id, e.g.

```shell
$ terraform import alicloud_itag_label_user.example <tenant_id>:<user_id>
```

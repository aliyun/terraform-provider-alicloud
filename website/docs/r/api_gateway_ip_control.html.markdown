# alicloud_api_gateway_ip_control

Provides a Api Gateway Ip Control resource. IP access control allows you to restrict API access with an allowlist (`ALLOW`) or blocklist (`REFUSE`) of IP addresses and, for allowlists, application IDs.

For information about Api Gateway Ip Control and how to use it, see [What is Ip Control](https://www.alibabacloud.com/help/en/api-gateway/developer-reference/api-cloudapi-2016-07-14-createipcontrol).

-> **NOTE:** Available since v2.3.0.

## Example Usage

### Allowlist with policy items

```terraform
terraform {
  required_providers {
    alicloud = {
      source = "aliyun/alicloud"
    }
  }
}

variable "name" {
  default = "terraform_example"
}

provider "alicloud" {
  region = "cn-hangzhou"
}

resource "alicloud_api_gateway_ip_control" "allow" {
  ip_control_name = var.name
  ip_control_type = "ALLOW"

  ip_control_policy_items {
    cidr_ip = "10.0.0.0/24"
    app_id  = "123456"
  }

  ip_control_policy_items {
    cidr_ip = "192.168.0.0/16"
  }
}
```

### Blocklist

```terraform
terraform {
  required_providers {
    alicloud = {
      source = "aliyun/alicloud"
    }
  }
}

variable "name" {
  default = "terraform_example"
}

provider "alicloud" {
  region = "cn-hangzhou"
}

resource "alicloud_api_gateway_ip_control" "refuse" {
  ip_control_name = var.name
  ip_control_type = "REFUSE"

  ip_control_policy_items {
    cidr_ip = "10.0.0.0/24"
  }
}
```

## Argument Reference

The following arguments are supported:

* `ip_control_name` - (Required) The name of the IP access control. It must consist of only letters, numbers, underscores (_) and hyphens (-).
* `ip_control_type` - (Required, ForceNew) The type of the IP access control. Valid values: `ALLOW` and `REFUSE`.
* `description` - (Optional) The description of the IP access control.
* `ip_control_policy_items` - (Optional, Computed) The list of IP control policy items. See [`ip_control_policy_items`](#ip_control_policy_items) below.

### `ip_control_policy_items`

The `ip_control_policy_items` supports the following:

* `policy_item_id` - (Computed) The ID of the policy item, generated by the server.
* `cidr_ip` - (Required) The CIDR IP address or IP segment of the policy item. Separate multiple IP addresses or CIDR blocks with semicolons (;), up to 10.
* `app_id` - (Optional) The application ID that the policy item restricts. This is only effective when `ip_control_type` is `ALLOW`; when `ip_control_type` is `REFUSE`, the gateway ignores `app_id` and only applies the IP restriction.

## Attributes Reference

The following attributes are exported:

* `id` - The ID of the Ip Control supplied above (the `ip_control_id`).
* `region_id` - The region ID of the Ip Control.
* `create_time` - The creation time of the Ip Control.
* `modified_time` - The last modification time of the Ip Control.

## Timeouts

The `timeouts` block allows you to specify [timeouts](https://developer.hashicorp.com/terraform/language/resources/syntax#operation-timeouts) for certain actions:

* `create` - (Defaults to 5 mins) Used when create the Ip Control.
* `update` - (Defaults to 5 mins) Used when update the Ip Control.
* `delete` - (Defaults to 5 mins) Used when delete the Ip Control.

## Import

Api Gateway Ip Control can be imported using the id, e.g.

```shell
$ terraform import alicloud_api_gateway_ip_control.example <ip_control_id>
```

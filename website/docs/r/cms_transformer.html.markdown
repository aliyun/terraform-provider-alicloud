# alicloud_cms_transformer

Provides a Cms Transformer resource.

For information about Cms Transformer and how to use it, see [What is Transformer](https://next.api.alibabacloud.com/document/Cms/2024-03-30/CreateTransformer).

-> **NOTE:** Available since v1.289.0.

## Example Usage

Basic Usage

```terraform
variable "name" {
  default = "terraform-example"
}

provider "alicloud" {
  region = "cn-hangzhou"
}

resource "alicloud_cms_transformer" "default" {
  transformer_name = var.name
  description      = "Transformer managed by Terraform"
  quit_after_match = false
  sort_id          = 1
  enable           = true
  workspace        = "default-workspace-cn-hangzhou"

  actions {
    label_key = "alert.name"
    source    = "$.data.alertName"
    target    = "alertName"
    type      = "MAPPING"
    mapping = {
      "key1" = "value1"
    }
    filter_setting {
      relation = "AND"
      conditions {
        field = "severity"
        op    = "EQ"
        value = "CRITICAL"
      }
    }
  }

  filter_setting {
    relation = "AND"
    conditions {
      field = "severity"
      op    = "EQ"
      value = "CRITICAL"
    }
  }
}
```

## Argument Reference

The following arguments are supported:
* `actions` - (Optional, List) The list of transform actions. See [`actions`](#actions) below.
* `description` - (Optional) The description of the transformer.
* `enable` - (Optional, Computed) Indicates whether the transformer is enabled. The value is applied through the dedicated enable and disable operations rather than the creation payload.
* `filter_setting` - (Optional, Set) The top-level filter setting for event matching. See [`filter_setting`](#filter_setting) below.
* `quit_after_match` - (Optional) Specifies whether to stop processing after the first match.
* `sort_id` - (Optional, Computed) The sort order of the transformer.
* `transformer_name` - (Optional) The name of the transformer.
* `workspace` - (Required, ForceNew) The workspace ID, which is used to isolate transformer resources for different business workspaces.

### `actions`

The actions supports the following:
* `filter_setting` - (Optional, Set) The action-level filter setting. See [`filter_setting`](#actions-filter_setting) below.
* `label_key` - (Optional) The label key for the transformed event.
* `mapping` - (Optional, Map) The field mapping table from source to target.
* `reg_exp` - (Optional) The content extraction regular expression.
* `source` - (Optional) The source path for data extraction.
* `target` - (Optional) The target field name after transformation.
* `type` - (Optional) The transform action type.
* `value` - (Optional) A static value for the transform action.
* `variable` - (Optional) The variable name for the transformed value.

### `actions-filter_setting`

The actions-filter_setting supports the following:
* `conditions` - (Optional, List) Filter conditions. See [`conditions`](#actions-filter_setting-conditions) below.
* `expression` - (Optional) The relational expression.
* `relation` - (Optional) The logical relationship between conditions.

### `actions-filter_setting-conditions`

The actions-filter_setting-conditions supports the following:
* `field` - (Optional) The filter field.
* `op` - (Optional) The filter operator.
* `value` - (Optional) The filter value.

### `filter_setting`

The filter_setting supports the following:
* `conditions` - (Optional, List) Filter conditions. See [`conditions`](#filter_setting-conditions) below.
* `expression` - (Optional) The relational expression.
* `relation` - (Optional) The logical relationship between conditions.

### `filter_setting-conditions`

The filter_setting-conditions supports the following:
* `field` - (Optional) The filter field.
* `op` - (Optional) The filter operator.
* `value` - (Optional) The filter value.

## Attributes Reference

The following attributes are exported:
* `id` - The ID of the resource supplied above. The value is formulated as `<transformer_id>:<workspace>`.
* `transformer_id` - The unique identifier of the transformer, which is generated by the server on creation.
* `create_time` - The creation time.
* `update_time` - The update time.
* `user_id` - The user ID.
* `region_id` - The region ID.

## Timeouts

The `timeouts` block allows you to specify [timeouts](https://developer.hashicorp.com/terraform/language/resources/syntax#operation-timeouts) for certain actions:
* `create` - (Defaults to 5 mins) Used when create the Transformer.
* `delete` - (Defaults to 5 mins) Used when delete the Transformer.
* `update` - (Defaults to 5 mins) Used when update the Transformer.

## Import

Cms Transformer can be imported using the id, which consists of transformer_id and workspace, e.g.

```shell
$ terraform import alicloud_cms_transformer.example <transformer_id>:<workspace>
```

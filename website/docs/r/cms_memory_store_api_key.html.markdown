# alicloud_cms_memory_store_api_key

Provides a Cms Memory Store API Key resource.

API keys are used to authenticate access to a CMS Memory Store. The key value is
generated by the server upon creation and cannot be updated; any change to the
identifying fields forces resource recreation.

-> **NOTE:** Available since v1.293.0.

## Example Usage

Basic Usage

```terraform
variable "name" {
  default = "terraform-example"
}

resource "alicloud_log_project" "default" {
  project_name = var.name
}

resource "alicloud_cms_workspace" "default" {
  workspace_name = var.name
  sls_project    = alicloud_log_project.default.project_name
}

resource "alicloud_cms_memory_store_api_key" "default" {
  workspace         = alicloud_cms_workspace.default.workspace_name
  memory_store_name = var.name
  name              = var.name
}
```

## Argument Reference

The following arguments are supported:

* `memory_store_name` - (Required, ForceNew) The name of the parent Memory Store.
* `name` - (Required, ForceNew) The display name of the API Key, used to identify its purpose.
* `workspace` - (Required, ForceNew) The name of the parent Workspace.

## Attributes Reference

The following attributes are exported:

* `id` - The ID of the resource. It is formatted as `<workspace>:<memory_store_name>:<name>`.
* `api_key` - (Sensitive) The full API Key value generated by the server. This field is sensitive and will not be displayed in plan output.
* `create_time` - The creation time of the API Key.
* `region_id` - The region ID of the resource.

## Timeouts

The `timeouts` block allows you to specify [timeouts](https://developer.hashicorp.com/terraform/language/resources/syntax#operation-timeouts) for certain actions:

* `create` - (Defaults to 5 mins) Used when create the Memory Store API Key.
* `delete` - (Defaults to 5 mins) Used when delete the Memory Store API Key.

## Import

Cms Memory Store API Key can be imported using the id, e.g.

```shell
$ terraform import alicloud_cms_memory_store_api_key.example <workspace>:<memory_store_name>:<name>
```
